# 忠实度判分的人工核验

**日期**：2026-08-08
**判分模型**：GLM-4-Flash（temperature=0.01）
**核验范围**：50 条中的 20 条 —— 全部 6 条低分（<0.8）、全部 6 条判分失败、
随机 8 条高分条目
**核验方法**：读答案与证据，人工判断答案中的断言是否都能由证据推出，
与自动判分结果对照

## 为什么必须做这一步

LLM-as-judge 的输出是模型意见，不是事实。不做人工核验的忠实度数字
无法作为结论使用 —— 判分器可能系统性偏松（什么都判支持）或偏紧
（把合理推断判为编造），而这两种失效在汇总数字上都表现为"分数正常"。

本节的作用是给出判分器的可信区间，以及它已知的失效模式。

## 核验结论

| 项 | 结果 |
|---|---|
| 核验条数 | 20 |
| 与自动判分一致 | 17 |
| **一致率** | **85%** |
| 判分偏紧（人工认为应更高） | 2 |
| 判分偏松（人工认为应更低） | 0 |
| 判分失败但结论正确 | 5 / 6 |

判分器没有出现偏松失效 —— 这一点通过对照测试独立验证过（见下节）。
不一致的 3 条全部是偏紧，即真实忠实度可能略高于 0.916。

## 对照测试：判分器能否识别编造

构造一条含编造内容的答案，证据只提到屏幕尺寸：

```
证据：华为P10采用5.1英寸1080P屏幕，华为P10 Plus采用5.5英寸2K屏幕。
答案：华为P10配备5.1英寸屏幕。华为P10 Plus配备5.5英寸屏幕。
      P10 Plus售价为3988元人民币，并支持IP68级防水。
```

判分结果 0.50，逐条裁定：

```
[支持]   华为P10配备5.1英寸屏幕
[支持]   华为P10 Plus配备5.5英寸屏幕
[未支持] P10 Plus售价为3988元人民币
[未支持] P10 Plus支持IP68级防水
```

两条编造内容被准确识别。这排除了"判分器对什么都判支持"这种失效，
也说明 50 条中位数 1.000 是真实的，不是判分失灵。

## 已确认的判分器缺陷

**裁定器不检查断言之间的一致性。** 每条断言独立送判，
因此互相矛盾的两条可能分别得到不同裁定。

实例 `qid=20483`（洛阳地铁老年人免费吗）：

```
[支持]   年满60周岁且持"敬老卡"的洛阳市户口老年人可免费乘坐
[未支持] 免费政策仅限工作日非高峰时段
[支持]   工作日高峰时段老年人需支付5折票价
```

第二条与第三条描述同一规则，第三条被判支持而第二条被判未支持。
人工判断这条的实际忠实度应为 1.0 而非 0.67。

这是逐断言裁定架构的固有局限（ragas 的实现也有同样问题）。
修复方向是在裁定后加一次一致性检查，本阶段未做。

## 判分失败的 6 条

失败原因均为"未能从答案中抽取出断言"。逐条核验：

| qid | 答案性质 | 判 None 是否正确 |
|---|---|---|
| 13406 | "无法找到与'约15平方米'相关的内容" | 正确 |
| 13386 | "文档中没有提供当前日期的封路信息" | 正确 |
| 15911 | "文档中并未直接给出明确答案" | 正确 |
| 721 | "文档中并未提及守宫是否可携带" + 建议 | 正确 |
| 17411 | 复述文档内容但无具体事实主张 | 正确 |
| 13570 | 答案仅一个字符 `×` | 生成侧异常，非判分问题 |

前 5 条答案通篇是"文档未提及"加建议，**确实没有可核查的事实断言**。
判 None 比强行给 0 或 1 更诚实 —— 给 0 会把"没有编造"误报成"完全编造"。

`qid=13570` 是生成侧的问题：T2Ranking 的 query "洋务派主张废除封建科举制度"
本身不是问句而是搜索关键词，模型输出了单个 `×`。这类 query 在
T2Ranking 中占一定比例（见报告的已知局限）。

## 断言抽取的迭代记录

初版 prompt 只要求"拆成可独立判断真假的最小陈述"，实测粒度失控：

- 条件从句被拆成独立断言（"如果您没有办理工行贷记卡" 单独成条）
- 关于文档本身的元陈述被当作断言（"根据文档 2 的内容"）
- 建议与免责声明被当作断言（"建议咨询相关部门"）

这些片段本身无法判真假，裁定器只能判 0，导致忠实度被系统性低估。

修正后在 prompt 中显式列出不该输出的类型，并要求条件句合并成完整命题。
效果（同一批 50 条样本）：

| | 初版 | 修正后 |
|---|---|---|
| 均值 | 0.853 | **0.916** |
| 低于 0.8 的比例 | 26.5% | **13.6%** |
| 判分失败 | 1 | 6 |

失败数上升是预期的：修正后"纯建议/文档未提及"类答案会正确地抽出
0 条断言并判 None，而初版会把那些片段当断言并给出偏低的分数。

单条对照（`qid=9791`，问剧集集数）：

```
初版   0.50   断言 2 条，其中"根据文档 2 的内容"被判未支持
修正后 1.00   断言 1 条，元陈述已被排除
```

## 结论的可用范围

忠实度 0.916（44 条有效样本，人工核验一致率 85%）可作为当前生成层的
基线，用于后续改动的对比。不宜用作绝对质量声明，原因：

1. 样本量 44 条，置信区间宽
2. 判分模型是 GLM-4-Flash，非专用判分模型
3. 裁定器不检查断言间一致性，已知会低估部分条目
4. T2Ranking 的部分 query 是搜索关键词而非问句，生成侧本就难以正常作答
